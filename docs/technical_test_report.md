## 项 1：表格顺序与位置

**完成标准**：不漏段、不重复段；下游明确哪些表格文字未检查。

### 测试方法

程序化构造最小样本「正文段 → 2×2 表格（r2c1 含两个段落）→ 正文段」，直接断言解析器输出：

1. `body_order` 是否保持「body/p1 → table1 → body/p2」的文档顺序；
2. 表格段落路径是否逐一为 `table1/r1c1/p1`、`table1/r1c2/p1`、`table1/r2c1/p1`、`table1/r2c1/p2`、`table1/r2c2/p1`；
3. 表格内容是否混入正文段落列表（应不混入）、路径有无重复；
4. `unchecked_parts` 是否声明「表格内 5 个非空段落已解析，段落规则尚未应用」。

### 测试结果

| 探针 | 结果 | 证据 |
|---|---|---|
| 顺序与路径 | ✅ | `body_order` 与 5 条 `table/r/c/p` 路径逐一相等 |
| 不漏段、不重复段 | ✅ | 正文段落恰为 2 段；表格 5 段文本齐全；路径无重复 |
| 未检查声明 | ✅ | `unchecked_parts` 含「表格内 5 个非空段落…」 |

**结论**：达成。表格文字的「已解析、规则未应用」状态对下游是显式的。

## 项 2：页眉页脚

**完成标准**：页码规则对生效页脚既不漏检也不重复报错；视觉页码另行验收。

### 测试方法

四个场景，均在大字版合规底稿上构造，先查解析器再跑完整 `engine.check`：

1. **两节继承**：第 2 节页脚链接上一节。断言 `story_links` 记录 `section2 → section1`、页脚只解析 1 份、整篇零 Finding；附带验证页眉已解析且声明未检查。
2. **三节中间覆盖**：第 2 节取消继承、改手打页码（无 PAGE 域、居左），第 3 节继承第 2 节。断言 Finding 恰好 2 条且全部定位「第2节」，第 3 节不重复报错。
3. **首页／偶数页／普通三类**：首页手打居左、偶数页手打居中、普通页脚合规。断言三类 `kind` 与位置标签齐全；Finding：首页 2 条（无 PAGE 域＋未居中）、偶数页 1 条（无 PAGE 域）、普通 0 条。
4. **未开启时不解析**：未开「首页不同／奇偶页不同」的文档只应有 `default` 一类故事。

### 测试结果

| 探针 | 结果 | 证据 |
|---|---|---|
| 两节继承 | ✅ | `story_links["section2/default/footer"] == "section1/default/footer"`；`footer_paras` 仅 1 条；零 Finding；页眉「内部资料」已解析并声明未检查 |
| 三节中间覆盖 | ✅ | Finding 恰 2 条（无 PAGE 域、未居中），位置均含「第2节」；无「第3节」Finding；`story_links` 含 `section3 → section2` 且第 2 节自身不记链接 |
| 三类页脚 | ✅ | `kind` 集合 = {default, even, first}；位置标签「普通页脚／首页页脚／偶数页页脚」正确；Finding 分布 2／1／0 与预期一致 |
| 未开启不解析 | ✅ | `kind` 集合仅 {default} |

**结论**：达成。「实际生效的故事来自哪一节」由 `story_links` 可追溯；继承页脚不重复解析、不重复报错；取消继承的失效页脚能被检出。视觉页码（逐页实际显示）按评审意见另行人工验收。

## 项 3：样式有效值

**完成标准**：每个现行规则用到的值及来源都正确；主题字体等单列未覆盖。

### 测试方法

分别构造四层来源的最小样本，断言解析器的有效值与 `sources` 来源记录：

1. **字符样式**：自定义字符样式（黑体 16 磅）挂在 run 上，run 无直接格式；
2. **段落样式链**：子样式给字号（18 磅）、父样式给字体（楷体），run 直接设加粗；
3. **直接覆盖**（反例）：段落样式宋体、run 直接设仿宋，run 必须赢；
4. **docDefaults**：run 与样式都不设，值落到文档默认层。

### 测试结果

| 探针 | 结果 | 证据 |
|---|---|---|
| 字符样式 | ✅ | `font_ea=黑体, size_pt=16`，来源均 `character_style:MyChar` |
| 段落样式链＋直接覆盖 | ✅ | 字体 `楷体` ← `paragraph_style:BaseA`；字号 `18` ← `paragraph_style:ChildB`；加粗 `True` ← `run` |
| 直接覆盖优先 | ✅ | 有效值 `仿宋`，来源 `run`（样式宋体被正确压制） |
| docDefaults | ✅ | `font_ea=仿宋_GBK`，来源 `doc_defaults` |

**结论**：达成。四层优先序（run > 字符样式 > 段落样式链 > docDefaults）全部正确且来源可断言。主题字体（`eastAsiaTheme`）不在解析层覆盖，见项 12。

## 项 8：错字边界

**完成标准**：分句后原文、起止偏移、建议位置一致；失败和跳过可追踪。

### 测试方法

1. **位置往返**：合规底稿正文注入「部署→布署」，启发式链路跑 `run_typo_check`，断言 Finding 的 `para_index`／`sent_start` 切回原文恰为错字本身、`original/suggestion` 正确、所在句与分句结果一致；
2. **长句二次切分**：>60 字、错字在段落中部的子句里，断言偏移仍指回原文、所在句是逗号切出的子句；
3. **跳过与状态**：7 种典型行（文号／日期／页码／身份证／英文／过短／正常句）验证过滤计数、跳过总量与报告状态；
4. **精检失败**：纠错器抛异常，断言按句计数、带位置写入未检查清单、状态为「运行失败」。

### 测试结果

| 探针 | 结果 | 证据 |
|---|---|---|
| 位置往返 | ✅ | `para_text[sent_start : sent_start+2] == "布署"`；`(布署→部署)` 正确；所在句以「。」结尾（短段未误切） |
| 长句子句偏移 | ✅ | 样本段 70+ 字触发二次切分；偏移切回原文仍为「布署」；所在句以「，」结尾（子句级定位正确） |
| 跳过与状态 | ✅ | 跳过 6／共 7 句；状态「未检查」（不为「通过」）；ELECTRA／精检未执行均列入未检查清单 |
| 精检失败 | ✅ | 4 句嫌疑全部计为失败；状态「运行失败」；未检查清单含「第4段第1字起精检失败：RuntimeError…」 |

### 发现的缺陷（1 处，已 xfail 固定）

**过滤原因标注失真**：`should_skip` 把「非中文为主」（CJK 占比 < 0.6）排在文号／日期／页码／证件号码等专用模式**之前**。实测「泰纪发〔2026〕5号」「2026年9月18日」「— 3 —」「11010119900307775X」全部先命中「非中文为主」（实测 `{"非中文为主": 5, "过短": 1}`），四个专用原因几乎不可达。
**影响**：跳过决策本身正确（这些句子确实不该进检测器），但原因统计失真，会干扰 T-01「用标注样本测过滤漏检」的归因分析。
**建议**：专用模式前移到 CJK 占比判断之前。探针 `test_t8_specific_skip_reasons_take_precedence` 已以 xfail(strict) 固定期望行为。

## 项 12：解析边界

**完成标准**：每种样本有明确的「正确解析」或「未检查」断言，不靠猜测补齐全部 OOXML。

### 测试方法

按真实输入频率选三类边界，每类两条探针：一条固定**当前实际行为**（防止静默变化），一条以 xfail 固定**期望的显式「未检查」声明**。跨节链接已在项 2 覆盖（`story_links`）。

1. **主题字体**：run 只设 `w:eastAsiaTheme="majorEastAsia"`，不设显式字体；
2. **表格样式**：自定义表格样式携带黑体，单元格 run 无直接格式；
3. **嵌套表格**：外层单元格含直接文字 + 内层 1×1 表格。

### 测试结果

| 探针 | 结果 | 证据 |
|---|---|---|
| 主题字体：不猜测 | ✅ | `font_ea is None` 且无来源记录——解析器没有把主题字体猜成某个值 |
| 主题字体：显式未检查 | ❌ xfail | `unchecked_parts` 无「主题字体」条目。**风险**：`font_format` 会把 `None` 当「未设置」报错，对用主题字体的真实文档构成误报 |
| 表格样式：不静默生效 | ✅ | 单元格 run `font_ea is None`——表格样式字体未被错误套用 |
| 表格样式：显式未检查 | ❌ xfail | `unchecked_parts` 无「表格样式」条目 |
| 嵌套表格：现状固定 | ✅ | 外层「外层文字」正常解析；内层「嵌套文字」不进 IR（python-docx `cell.paragraphs` 不含嵌套表格） |
| 嵌套表格：显式未检查 | ❌ xfail | 嵌套表格文字**静默丢失**，`unchecked_parts` 无声明——这是三处缺口中最严重的，因为完全无声 |

### 缺口汇总与建议

| 缺口 | 当前行为 | 风险 | 建议 |
|---|---|---|---|
| 主题字体 | 值解析为 None，不声明 | 误报（「未设置」） | 检测到 `*Theme` 属性时写入 `unchecked_parts`，并在 `font_format` 对 None 值区别「未设置」与「未解析」 |
| 表格样式 | 不应用，不声明 | 漏检（样式设的字体绕过检查） | 表格带样式时写入 `unchecked_parts` |
| 嵌套表格 | 文字静默丢失 | 漏检（整段文字消失） | 单元格内含 `w:tbl` 时写入 `unchecked_parts`；按真实输入频率决定是否扩 IR |

三处缺口的修复都不需要先扩 IR，只需在解析器里补 `unchecked_parts` 声明——与 F-05「未检查状态必须显式」的原则一致。
