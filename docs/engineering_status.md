## 1. 项目目标与当前结论

项目面向 DOCX 文档的两条质检链路：

1. **格式检查**：解析 Word → 文档中间表示（IR）→ 段落角色映射 → 按 YAML 规则调度 Python 检查器 → 输出 Finding 报告。
2. **错别字检查**：复用 Word 解析 → 过滤无需检查的内容 → 分句并保留偏移 → ELECTRA 初筛嫌疑句 → 4B 或现有 27B 模型精检 → 输出建议。

当前阶段以跑通功能、验证技术路线和准备部署为主。前端、对外接口、两项功能可用算力及响应时间目标尚待下周讨论。开发环境先用英伟达，最终目标是华为 300I A2；英伟达或 CPU 环境中的结果不能直接当作华为环境部署验证。

**截至本次更新：格式检查在合成及 19 个带分层标注的 Word 案例（16 份不同 DOCX）上形成可重复回归；错别字的过滤、分句、启发式链路和状态处理有自动测试。ELECTRA 曾在历史实验中运行，本轮未联调权重；4B／27B 精检、视觉检查和华为部署均未验证。样本 gold 仍待业务人工复核。**

### 代码数据流

```text
DOCX
  └─ docx_parser → DocModel
       ├─ role_mapper → 角色集合 → rule_engine → YAML → checkers → 格式 Report / JSON
       └─ filters → splitter → detector → corrector → 错别字 Markdown / JSON Report
```

`DocModel` 已记录正文与表格段落、正文出现顺序、节页面参数、页眉、普通／首页／偶数页页脚、故事继承链接、行内图片计数与未检查范围。现行规则所需的部分有效样式可追溯来源；真实分页、坐标、主题字体的实际名称、表格样式继承与完整 OOXML 样式体系尚未进入稳定 IR；相应未解析范围已显式标记。具体扩展顺序见 [TODO](TODO.md)。

### 5.2.1 Q1、Q3、Q4 暂定口径

**Q1（10 号样本，标题序号）**

- 依据：[GB/T 9704-2012 7.3.3](https://dzb.cumtb.edu.cn/info/1040/1184.htm)列举结构层次序数“一、”“（一）”“1.”“（1）”。它没有直接禁止正文中任何“1、”列举。
- 假设：10 号段首“1、”暂作疑似结构编号，现有 heading-number error 保留；gold 的 body 是当前版式映射结果，并非已确认语义角色。
- 待确认：业务判定第 11 段究竟是标题还是正文列举、此规则的文书适用范围以及 error/warning 级别。

**Q3（11 号样本，成文日期）**

- 依据：[GB/T 9704-2012 7.3.5.4](https://dzb.cumtb.edu.cn/info/1040/1184.htm)要求阿拉伯数字标全年月日，月日不编虚位。
- 假设：暂按真实公历日期 YYYY年M月D日 校验；点号、短横、月日补零及不存在的日期均为 error。11 号 gold 保持 2026.9.18 反例。
- 待确认：本项目各类卷宗是否都适用成文日期规则，内部是否另有明确放宽。

**Q4（12 号样本，署名前下空二行）**

- 依据：内部《常用公文格式》落款照片写“下空二行”；国标 7.3.5.2 对**不盖章的单一机关公文**写“下空一行”，两种场景须由业务厘清。
- 假设：暂用署名前**两个空 Word 段**且每段固定行距与该版式正文相同作代理（大字版 32 磅、小字版 29.5 磅）。空段数或行距不符报 warning；12 号 gold 只有一个空段。
- 待确认：内部二行要求适用哪些盖章／不盖章文书；业务是否接受此代理和 warning 级别；真实视觉行数仍待渲染样本验证。

表格 Q2 保持“已解析、规则未适用、报告为未检查”；见[业务复核清单](business_review_q1_q4.md)。以上均是工程暂定口径，19 份 Word gold 的 annotated_by 仍标“AI 起草，待业务人工复核”。

## 9. 已知风险与汇报口径

| 风险 | 影响 | 控制方式 |
|---|---|---|
| 生成器与检查器共用 YAML | 双方同时写错时测试仍可能通过 | 加人工标注的原始 Word，保留合成回归但不当作独立准确率 |
| 角色依赖外观 | 错字体／字号可能让段落被归到错误角色 | 独立测试角色，允许未知角色，结合样式、结构和业务示例 |

| 模型自动回退 | 启发式运行被误报为模型成功 | 报告记录实际后端、失败和跳过数 |
| 模型环境迁移 | NVIDIA 成功不保证华为可运行 | 在 300I A2 上设独立验收关口 |
| 需求迭代 | 过早固化角色、B／C 规则、前端接口会返工 | 基础解析与规则机制先做，产品口径待确认后定稿 |
