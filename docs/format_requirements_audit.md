## 结论与状态定义

**结论：没有全部实现。** 大字版、小字版的字体／字号、边距、固定行距、字符间距和基础页码已进入规则链路，并在同一规则集生成的合成 DOCX 上通过回归。19 个 Word 案例（16 份不同 DOCX）已为混合 run、部分样式继承、表格解析和奇偶页页脚建立回归；gold 仍待业务人工复核，表格段落规则与视觉定位未完成。「其他注意事项」照片中的结构和印章规则大多只有部分启发式实现或完全未做。

- **基础可检**：已有 YAML、解析字段与检查器，同类核心路径在合成样本上有正反验证；表内个别参数仍缺单独负例，也不代表真实文档稳定。
- **部分**：某些子条件有代码，但存在明确漏检／误报边界，或未由独立测试覆盖。
- **未实现**：没有相应判定逻辑；仅提示、参数或注释不算实现。
- **待确认**：图片没有规定该属性，项目却将其设为强制规则；需要业务确认。

检查器入口见 `src/document_checker/rules/`、`src/document_checker/checkers/basic.py`、`structure.py`。是否命中检查器还取决于 `role_mapper.py`；表格正文已解析但未套用段落规则，奇偶页页脚已解析并参加页码检查；真实分页和坐标尚无数据层。

## 为什么现有测试仍不能证明全部完成

`tests/test_synthetic.py` 的两套合规样本与检查器共用 YAML，且每套仅有 12 类合成变异。测试检查「期望规则 ID 是实际报错集合的子集」，未禁止额外误报，也不验证 Finding 的位置和实际值。变异覆盖字体、字号、加粗、左边距、行距、字符间距、页码横线＋对齐的组合、一级编号、附件末标点、日期写法、密级加粗；未覆盖「其他注意事项」和「落款印章」照片中大多数几何、条件分支与续行规则。

2026-09-27 的回归为 **90 passed**；2026-09-28 收紧 gold 后为 **105 passed**，Q1/Q3/Q4 与技术探针加入后为 **137 passed, 4 xfailed**；四处探针缺口修复后为 **143 passed**。

| 反例 | 当前结果 | 原因 |
|---|---|---|
| 正文首 run 字体正确，第二 run 为宋体 | 已检出 | `font/02` 人工 Word 样本固定回归 |
| 有 PAGE 域但显示文本为「—  —」 | 已检出 | 独立的空数字域与 NUMPAGES 回归 |
| 「秘 密」移到正文后 | 已检出 | 全文密级候选与位置检查 |
| 「附件」前仅一个全角空格 | 已检出 | `attachment/09` 人工 Word 样本固定回归 |

因此目前最准确的表述是：**规格表的主要数值规则已有合成样本级实现；注意事项第 1—6 条只完成部分启发式；第 7 条的盖章与排版位置规则基本未实现。**

## 建议处理顺序

1. **继续处理未覆盖范围**：表格已解析但未套用正文规则；角色冲突与复杂继承仍需样本和明确口径。规则类型、YAML、全 run、页码空数字与密级错位已修复。
2. **建立独立的图片条款测试表**：每个子要求至少一份正确、一份单点违规 DOCX；特别覆盖大小字版、小字版粗体解释、奇偶页、附件续行和盖章两分支。标注规则 ID、段落、属性、期望值。
3. **与业务确认图片外的强制要求**：小字版「不得加粗」、标题居中、必须用 PAGE 域、成文日期写法；同时明确「一字／一行」按字符、段落还是渲染尺寸计算。
4. **实现尚缺的确定性规则**：文号西文字体、三四级标题字体、精确密级空格、附件编号与缩进、无章落款的右空字数。
5. **最后处理视觉规则**：确定 Word→PDF 工具和目标字体，测实际页码位置、附件续行和署名日期几何关系；在华为 300I A2 环境复验渲染与模型依赖。

验收时应分别给出「规则存在」「合成负例通过」「人工 Word 负例通过」「目标环境通过」四列，不再用单个 ✅ 表示全部完成。
