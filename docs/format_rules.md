# 公文格式规则（需求侧原件）

来源：《常用公文格式》内部要求（参考 GB/T 9704-2012），三张纸质照片整理。
本文件是规则的**需求侧源头**；`src/document_checker/rules/*.yaml` 是本文件的机器可读派生。
需求对齐时先改本文件，再同步 YAML。
三张原图的逐条检测方法、代码证据和未实现项见 [格式要求审计](format_requirements_audit.md)。

分类：**A＝直接格式**（段落/run 属性可直接判定）｜**B＝结构规则**（依赖位置/顺序/上下文）｜**C＝视觉规则**（需渲染+VLM）
当前实现范围：A 类检查器已在合成 DOCX 上跑通，真实 Word 的完整覆盖仍待验证；B 类已超前实现（标注 ⚠，口径待需求确认）；C 类仅预留接口。表中的 ✅ 表示已有对应实现，不表示独立准确率或真实文档验收通过。

## 一、呈报稿（大字版）——一般适用于向委领导呈报的材料

| 项目 | 要求 | 分类 | 实现 |
|---|---|---|---|
| 标题 | 方正小标宋 GBK，小一，加粗 | A | ✅ |
| 正文 | 方正仿宋 GBK，小二，加粗 | A | ✅ |
| 一级标题 | 方正黑体 GBK，小二，加粗 | A | ✅ |
| 二级标题 | 方正楷体 GBK，小二，加粗 | A | ✅ |
| 页面设置 | 上 3.8cm、下 3.3cm；左 2.7cm、右 2.7cm | A | ✅ |
| 行距 | 固定值 32 磅 | A | ✅ |
| 字符间距 | 加宽 0.4 磅 | A | ✅ |
| 页码 | 格式"— 1 —"，居中，宋体，四号 | A | ✅ |

## 四、适用范围（不可自动检查，仅元信息）

- 大字版：向委领导呈报的材料；小字版：正式红头文件。
- 文书类型自动识别当前用"标题字号"启发式（小一→大字版，二号→小字版），
  需求对齐后应改为显式指定或更可靠的判定。
